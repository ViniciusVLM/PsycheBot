# 🤖 PsycheBot - Orientação de Carreira com IA

O **PsycheBot** é uma aplicação web desenvolvida para apoiar o desenvolvimento profissional de jovens 
trabalhadores. Através de um formulário interativo, a plataforma coleta percepções sobre desafios 
no ambiente de trabalho e utiliza a inteligência artificial (Google Gemini 3) para gerar um parecer 
psicológico personalizado, focando em pontos de melhoria e recomendações de soft skills.

Este projeto foi criado especialmente para a gincana do **Dia do Jovem Trabalhador no CIEE**, 
unindo tecnologia de ponta com suporte ao crescimento de carreira.

### 🚀 Tecnologias Utilizadas
* **Python** (Back-end)
* **Flask** (Framework Web)
* **Google Gemini API** (Inteligência Artificial Generativa)
* **HTML5 & CSS3** (Interface com design moderno/Glassmorphism)
